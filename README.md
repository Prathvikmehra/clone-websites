# 🌐 Clone Websites Collection

## 🚀 Project Overview

Welcome to **Clone Websites** — a curated collection of pixel-perfect website clones built using pure HTML5 and CSS3. This repository showcases my ability to recreate modern, real-world UI designs with a strong focus on **responsive layouts**, **clean structure**, and **attention to detail**.

Each project is crafted to closely replicate the original website’s design, demonstrating my frontend development skills and understanding of layout systems, styling techniques, and visual consistency.

## 🖥️ How to View Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Prathvikmehra/clone-websites.git
   ```

2. Navigate into the project folder:

   ```bash
   cd clone-websites
   ```

3. Open any project folder and run the `index.html` file:

   * Double-click the file
   * OR open with Live Server (recommended for development)
